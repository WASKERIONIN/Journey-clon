# Рыбак у причала — исходный rig и анимации

`AnimationLibrary_Godot_Standard.glb` — стандартный glTF-набор **Universal Animation Library** от Quaternius, распространённый через `J-Ponzo/gltf-universal-animation-library`. Используется humanoid-меш/скелет и бесплатные клипы `Idle_Talking_Loop`, `Idle_Loop` и `Interact`.

- Автор исходного набора: **Quaternius**.
- Лицензия: **CC0 1.0 Universal**; полный текст рядом в `CC0-1.0.txt`.
- Репозиторий-источник: https://github.com/J-Ponzo/gltf-universal-animation-library
- Игровой слой переокрашивает импортированный меш под тёплую стилистику песчаных рыб, добавляет костно-привязанные дождевой жилет и рыбацкую шляпу; глаза рисуются процедурным шейдером.

В проекте сохранён один GLB с сеткой, скелетом и клипами; текстур и сетевых загрузок во время запуска нет.

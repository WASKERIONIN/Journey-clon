# Песчаное море — рыбалка на берегу

Море здесь сделано из песка: у кромки оно дышит мега-рябью и расходится
кольцами от шагов, а под «водой» ходят песчаные киты и всплывают к
поплавку. Игрок — путник от первого лица с удочкой: ходит по пляжу и
дюнам, заходит в воду по колено, поднимается на пирс, достаёт удочку,
забрасывает и вываживает рыбу. Внизу — компактный HUD рыбалки: что
нажать, сила заброса, окно подсечки, натяг и прогресс вываживания.

## Запуск

1. Godot **4.7.2 stable**, рендерер — **Forward+ (Vulkan)** (прописан в
   `project.godot`): нужен для волюметрического тумана, glow и SDF-существ.
   Нужен рабочий Vulkan-драйвер; без него Godot уйдёт в Compatibility —
   в консоли будет строка `WORLD: … Compatibility-фолбэк`, волюметрика
   заменится плотной дымкой.
2. Import → выбрать `project.godot` → **F5**.

Проект собирается программно в `_ready()` — отдельных сцен-демок нет,
запускается сразу играбельный берег.

## Управление

| Клавиши | Действие |
| --- | --- |
| `W A S D` / стрелки | движение |
| `Мышь` | обзор (курсор захвачен) |
| `Shift` | бег |
| `Пробел` | прыжок |
| `ЛКМ` | достать удочку → зажать (заряд) → отпустить (заброс) |
| `ЛКМ` во время поклёвки | подсечка |
| `ЛКМ` в вываживании | подматывать (в рывок рыбы — нельзя: растёт натяг) |
| `ЛКМ` на воде (поплавок уже заброшен) | смотать леску — поплавок идёт к берегу постепенно |
| `ПКМ` / `R` | вернуть снасть, отменить заряд |
| `Q` | убрать удочку |
| `E` у рыбака | поговорить; затем `1`–`3` выбрать задание |
| `F` | фонарик |
| `ESC` | отпустить/захватить курсор |
| `F3` | DEV-панель крутилок (по умолчанию скрыта) |

## Рыбалка

Механика перенесена из открытого проекта
[bridge-mind/tideline](https://github.com/bridge-mind/tideline) (Three.js,
MIT): ожидание с «тычками», короткое окно подсечки, бой на двух шкалах
(натяг/прогресс), рывки с предупреждением, усталость рыбы.
Управление и подсказки — в HUD (`scripts/fishing_hud.gd`).

| Файл | Что внутри |
| --- | --- |
| `scripts/fish_catalog.gd` | 16 видов (9 исходных + 7 новых FishKit), 5 редкостей, зоны, время, размер/вес/цена, баланс |
| `scripts/bite_system.gd` | ожидание 4.5–13 с, тычки, окно 0.84–1.21 с (по редкости), промах |
| `scripts/fish_fight.gd` | натяг 0–100, прогресс 0–100, рывки, усталость, сход/обрыв, посадка |
| `scripts/catch_fish.gd` | контроллер позы; пойманная рыба рисуется тем же SDF-шейдером |
| `scripts/catch_card.gd` | карточка улова на 5 с (+ «новый вид») |
| `scripts/fishing_hud.gd` | подсказки, сила заброса, окно подсечки, натяг/прогресс, сматывание, зона и время |

К каталогу рыбалки добавлены семь видов из `godot_fish/`: Дюнный странник,
Угорь-лента, Фонарник, Песчаная манта, Стрела, Пухляк и Усач-грунтовик.
Они доступны как реальные результаты поклёвки с отдельными размерами,
палитрами и характером боя; три вида одновременно плавают в воде через
общий SDF-шейдер и плавно меняются морфом. Действующий `FishKit` и старый
рыболовный цикл `RodCast` остаются совместимы.

**Цикл.** ЛКМ достаёт удилище; зажать — заряд силы (видно и по изгибу,
и по полоске в HUD), отпустить — заброс на 6–48 м по дуге. Поплавок падает на воду (или
честно на песок — рыбы туда не придут). Дальше:

1. **Ожидание** — 4.5–13 с, с поправкой на зону, время суток и ветер.
   Рыба «примеряется»: 1–2 тычка, поплавок вздрагивает, по воде идут
   кольца.
2. **Поклёвка** — поплавок ныряет, над ним загорается тёплое кольцо,
в HUD бежит полоска окна подсечки, звук, удилище клюёт. Окно подсечки
   зависит от редкости: обычная 1.21 с, легендарная 0.84 с. Промах не
   отменяет заброс — рыба уходит, ожидание начинается заново.
3. **Подсечка** — ЛКМ в окно. Рыба «выкатывается»: зона и время суток
   определяют, кто именно клюнул (мелководье/отмель/глубина; день/закат/ночь).
4. **Вываживание** — две шкалы, обе видны в HUD: **натяг** и **прогресс**.
   Держишь ЛКМ — прогресс растёт, натяг тоже; отпустил — натяг падает,
   но рыба забирает леску. Рыба делает **рывки**: сначала 0.75 с
   предупреждения (всплеск, прыжок крупной рыбы), потом 1.1–1.9 с
   активной фазы — в это время подматывать нельзя, натяг взлетает.
   Натяг 100 — леска рвётся; прогресс 0 дольше 2.5 с — рыба сходит.
   Через 9–24 с рыба устаёт: сила ×0.62, рывки реже.
5. **Поимка** — рыба подходит к ногам, вылетает из воды по дуге в руки,
   карточка улова. Натяг дополнительно читается по изгибу удилища и
   дрожи кончика.

**Сматывание.** ЛКМ (или R) на заброшенной снасти не дёргает поплавок
телепортом: леска наматывается на катушку ~5.8 м/с, по воде идут кольца,
слышны щелчки трещотки, в HUD растёт полоска «смотано».

Звук и карточка висят на сигналах `RodCast`: `cast_started`,
`bobber_landed`, `cast_landed_on_sand`, `bite_window_started`,
`fish_hooked`, `fish_landed`, `fish_escaped`, `bite_missed`,
`line_snap`, `tension_changed`, `surge_telegraph`, `line_retrieved`,
`reel_tick`, `fish_caught` (см. `main.gd::_connect_fishing()`).

## Мир

### Берег (`scripts/coast.gd`)

Аналитический рельеф: урез, пляж с бермой, дюны с гребнями, дальняя
стена дюн до горизонта, закрытый залив по краям и морское дно со свалом.
Сетка 900×900 м (760×760 вершин), ходьба и камера читают ту же функцию
`ground_height()`, что и шейдер, — песок под ногами совпадает с картинкой.
Запечённый горизонтный AO (8 азимутов × 3 дистанции) даёт объём ложбинам.

### Настоящий песок (`scripts/sand_field.gd`)

Три слоя карт высот, как в Journey:

- **Дюны** — сетка высот берега.
- **Мега-рябь** — настоящая геометрия (волны ~9 м гребнями поперёк ветра).
- **Следы** — физическое поле смещений: тор-карта 800×800 текселей
  (0.12 м/тексель), окно 96×96 м скользит за путником. Отпечаток стопы
  (пятка глубже, вал выброшенного песка), посадка после прыжка, борозда
  от бега. Свежие следы оседают, осыпаются круче угла откоса и заносятся
  ветром (полураспад ~15 с). Шейдер песка изгибает геометрию по карте
  смещений, а `Coast.ground_height()` подмешивает её в физику. Ночью на
  песке видны редкие четырёхлучевые искры, закреплённые в мировых
  координатах: это не экранный слой — они проявляются только в реальных
  тенях от свай пирса и камней через shadow attenuation.

Море (`shaders/water.gdshader`, `scripts/water_surface.gd`) — отдельная
стихия с собственной палитрой: бирюзовое мелководье, синий индиго на
глубине, тёплая солнечная дорожка. Плотная сетка у берега и геометрически
растущая к горизонту (до 3.6 км), мега-рябь, глиттер, кольца от шагов,
поплавка и прыжков рыб. `WaterField` — CPU-зеркало шейдера: даёт физике
высоту поверхности в точке, поэтому поплавок качается ровно на тех волнах,
что видит глаз.

**Урез** — гладкий контур, а не граница треугольников. Шейдер моря
получает от `Coast` карту высот поверхности (`height_tex` — те же
вершины, что у меша берега) и считает глубину **по фрагменту**: высота
воды минус высота песка в этом пикселе. Поверхность моря — ровная
плоскость со своим «дыханием»; она пересекает песок по мокрой кайме,
которая ползёт по пляжу вместе с накатом, а альфа растёт от нуля по
глубине, поэтому стык — плавный градиент без лоскутов и висящих пластин.
Мокрую полосу и пену на суше рисует `sand.gdshader` по той же формуле
волны, пену на воде — `water.gdshader` по контуру глубины. Плюс depth-фейд
по буферу сцены: вода мягко обтекает пирс и коряги.

**Суша и вода** намеренно разных палитр: песок медово-оранжевый (кромка —
тёмная тёплая, без синевы), море бирюзово-синее. Волн-лент ветра на суше
больше нет: песок рисует только собственную рябь и следы.

### Пирс и декор

`scripts/pier.gd` — настоящий настил на сваях от пляжа на 26 м в море,
с фонарём, который загорается ночью; по нему можно ходить (высота пола
подмешивается в `surface_at`). `scripts/props.gd` — шесть «морских
пальцев» в воде, коряги, выброшенные прибоем, и камни у подножия дюн
(всё — `MeshKit`, вершинный цвет, три draw-call-группы). У входа на пирс
стоит рыбак — **песчаное существо из того же SDF-шейдера, что и рыбы**
(`sand_sea_sdf.gdshader`): тело «плавится» из капсул по костям CC0-рига
Quaternius (`assets/npc/`, клипы `Idle_Talking_Loop`, `Idle_Loop`,
`Interact` — риг скрыт, но двигает суставы), на нём жилет, кепка и
сапоги, а лицо — объёмные глаза с радужкой, бликами и веками: они
следят за игроком, моргают (иногда дважды), а рот болтает в диалоге.
Подойди и нажми `E`; затем `1`–`3` выбирают контракты на три любые
рыбы, крупный трофей или ночной улов.

### Песчаные киты (`scripts/sand_fish.gd`)

Пять существ живут в воде у уреза, ходят кругами, выпрыгивают из-под
песка и всплывают к поплавку. Рисуются одним quad-ом через SDF-шейдер
(`sand_sea_sdf.gdshader`, Forward+): веер хвоста, плавники, капли.
Палитра — та же, что у песка и моря, поэтому день/ночь красит и рыб.
**Зона плавания — по глубине, а не по расстоянию от берега**: рыбы
спавнятся на глубине 2.3–8 м (для своего размера), курс выбирают по
батиметрии (три пробы вперёд-вбок — туда, где глубже), с мели их
выталкивает градиент дна, а прыжки разрешены только там, где тело не
сядет на песок. Тот же принцип держит FishKit-виды (`godot_fish/`),
живущие вокруг своей «домашней» точки, а не мирового нуля.

### Небо, свет, пост

`scripts/world.gd`: Sky++ (Rayleigh + Mie + ozone, raymarched cumulus,
CC0 — `third_party/sky_plus_plus/`), направленное солнце, волюметрический
туман, Filmic-тонмаппинг, glow, виньетка. В Compatibility автоматически
остаётся лёгкое процедурное небо. `scripts/color_grade.gd` — 6 пресетов
грейдинга (по умолчанию «Золотой час», сила 0.5); ночь включается одним
числом `main.set_time(night01)` — оно красит небо, свет, песок, море,
существ и грейдинг.

### Ночь без фонаря и «чёрный пиксельный песок»

Симптом: ночью песок под ногами превращался в чёрные прямоугольники
(«пиксели»), а с включённым фонарём всё было нормально. Причины было три,
и они чинились вместе:

1. **SSAO + SSIL** в Forward+ считаются в половинном разрешении; на
   большой плоскости пляжа под скользящим ракурсом они дают чёрные
   прямоугольные острова. В связке с PSSM-тенями и MSAA 4x это известные
   «black square artifacts» (godotengine/godot#103669, #81060).
   Теперь экранное AO **выключено по умолчанию**, а объём дюн даёт
   запечённый AO (`AO` в шейдере песка, UV2 из `Coast`) и настоящие тени.
   Тумблер — в DEV-панели, раздел «ГРАФИКА / АРТЕФАКТЫ».
2. **MSAA 4x** (`msaa_3d=2`) — второй участник той же связки. В проекте
   теперь 2x: лесенка на дюнах убрана, а известная комбинация не собирается.
3. **Свет ночью держался на фонаре**: ambient был 0.42, «луна» — 0.30
   энергии, а песок пёк весь свет в `EMISSION`. Стоило выключить фонарь —
   и в кадре оставалась ровная тёмная заливка. Теперь ночью ambient 1.35,
   луна 1.05, песок и море имеют честные ночные палитры, emission — только
   небольшая добавка с лунной нормалью и запечённым AO.

Проверка в CI: кадры `shot_t_night_sand_off.png` (ночь, фонарь выключен,
взгляд вниз на песок), `shot_u_night_sand_on.png` (тот же ракурс с фонарём)
и `shot_v_night_sea.png` (ночное море).

Фонарь теперь — честный конус (`spot_attenuation = 1.05`, энергия 3.6,
30°), а не «прожектор, который не гаснет»: ночь должна читаться без него.

### Звук (`scripts/audio.gd`)

Всё синтезируется кодом в `AudioStreamWAV` при запуске: 6 вариантов шага
по песку, шаги по воде, брод, посадка, заброс, всплеск, шлепок по песку,
поклёвка, подсечка, щелчки катушки, поимка и уход рыбы, ветер с
дышащим фильтром, тихий амбиент-пад с «сиянием». Шины: Sand, Wind,
Music. Реактивность — от `sprint01`, `wet01` и высоты. Бинарных
аудио-ассетов в проекте нет.

### DEV-панель (F3)

Главный ползунок — **«Время суток (0=день, 1=ночь)»**: одним движением
красит небо, свет, песок, море, рыб и грейдинг. Дальше: высота/азимут
солнца, яркость, Mie, слой Рэлея, мультирассеяние; облака (покрытие,
размер, дрейф); песок (блёстки, рябь, мега-рябь, дымка); море (дыхание,
кольца, глиттер, рябь); экспозиция, порог glow; грейдинг (пресет, сила,
тепло, контраст, вибранс, «ночь Пуркинье»); волюметрика (плотность,
дальность, анизотропия, подсветка неба), фонарик, направление ветра,
счётчик FPS.

Сверху — раздел **«ГРАФИКА / АРТЕФАКТЫ»**: A/B-тумблеры `SSAO/SSIL`
и `MSAA 4x` (по умолчанию выключены/2x — см. выше). При открытии панели
ползунки подтягивают ЖИВЫЕ значения из сцены, а не дефолты: раньше
«Ночь (Пуркинье)» показывала 0.000 при включённой ночи.

## CI

`.github/workflows/validate.yml` на каждый push:

1. headless-импорт (`--import`) — падает на `SCRIPT ERROR`/`Parse Error`;
2. автотест геймплея `JOURNEY_SMOKE=1` (`scripts/smoke_test.gd`, 6 фаз:
   мир/берег/пирс → ходьба → брод → заброс → поклёвка/вываживание/поимка
   → возврат снасти, `Q`, заброс на песок) — падает на `SCRIPT ERROR`
   и `Invalid get/call/set`, код возврата 1 при провале;
3. рендер-проверка шейдеров под xvfb + Vulkan lavapipe и контрольные кадры
   (`scripts/shot_taker.gd`: берег, удочка/поплавок, рыбалка, ночные искры
   в тенях, пирс, новый human-rig, окно контракта, ночной песок без фонаря
   и с фонарём, ночное море) — кадры и логи коммитятся в `.ci-logs/`.

```
shaders/color_grade.gdshader — полноэкранный грейдинг
```

Всё процедурное: геометрия — код, шейдеры — текст, текстуры и звук
генерируются кодом, сцены собираются в `_ready()`. Бинарных ассетов нет.
